# Bắt đầu ở đây

1. Đọc README.md, cài Flutter và chạy app trên Android hoặc iOS.
2. Đọc user_stories.md; so với wording lab cũ nếu giảng viên yêu cầu nguyên văn.
3. Dựng 9 wireframes theo FIGMA_GUIDE.md trong Figma thật.
4. Chụp 17 screenshot thật theo EVIDENCE_GUIDE.md, lưu đúng tên vào evidence/.
5. Kiểm tra evidence/CHECKLIST.md và VALIDATION.md. Chỉ đánh dấu khi đã tự xác minh.
6. Tự upload project lên GitHub Public. Lấy URL repo/branch thật thay OWNER/REPO/BRANCH trong SUBMISSION.md.
7. Nộp từng mục 1–28 theo SUBMISSION.md: mục link paste URL thật; mục ảnh upload ảnh thật. Không nộp placeholder hay chỉ tên ảnh.
