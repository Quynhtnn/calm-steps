# Tạo 9 wireframes trong Figma thật

Chưa có Figma file được tạo trong tài khoản của bạn. Tài liệu này là đặc tả để tự dựng; không phải Figma evidence.

1. Mở Figma, tạo Design file tên Calm Steps — Final Project.
2. Tạo 9 phone frames 390 × 844, nền trắng, padding 24; màu chính teal #00897B. Dùng rectangle/text/icon đơn giản, chữ 16–24px; đây là wireframe, không cần ảnh stock.
3. Đặt frame theo 2 hàng: hàng 1 có 5 frame, hàng 2 có 4 frame. Đặt tên frame đúng bảng bên dưới.
4. Tạo các thành phần khớp app đang chạy. Để ít nhất một favorite Morning Calm ở Favorites/Profile. Dữ liệu Figma chỉ là dữ liệu thiết kế.
5. Trong Prototype mode, nối Log in/Sign up → Home; card → Detail; heart → Favorites/Profile; menu icon → Settings Menu; menu items → API/Settings/Notifications; back → màn hình trước.
6. Chụp màn hình Figma canvas thật, thấy tên các frame và thanh công cụ. Chọn 5 frame hàng 1 để zoom vừa màn hình → figma-evidence1.png; chọn 4 frame hàng 2 → figma-evidence2.png. Có thể thu gọn sidebar để dễ đọc. Không lấy app screenshot rồi gọi đó là Figma screenshot.

| Frame | Nội dung |
|---|---|
| Login | Logo, Welcome back, Email, Password, Log in, Sign up, link Sign up |
| Registration | Logo, Username, Email, Password, Sign up, link Log in |
| Home | Header logo spa + Calm Steps + menu; Welcome, Fiona!; 3 meditation cards có chevron; Favorites/Profile |
| Detail | Back, Morning Calm, hướng dẫn thở, heart, timer, Start |
| Favorites/Profile | Fiona, Morning Calm favorite, local storage snapshot |
| External API | Back, Mindful world, Live weather: Open-Meteo.com, danh sách temperature/wind/update time |
| Settings Menu | Favorites/Profile, Mindful world, Theme and preferences, Notifications, Help, Log out |
| Settings Screen | Dark mode toggle, duration dropdown, Language English, Configure notifications |
| Notifications Screen | ON/OFF, Reminder title, selected date/time, picker, Schedule reminder, Test in 15 seconds, status |

Frame API trong Figma là wireframe; evidence-api-ux.png phải chụp dữ liệu app lấy thật. Frame Notifications là wireframe; evidence-notification-alert.png phải chụp OS alert thật.
